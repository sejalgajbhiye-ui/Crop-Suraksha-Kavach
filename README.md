# Crop Suraksha Kavach

## AI-Based Smart Animal Detection and Farmer Alert System

### 📖 Overview
Crop Suraksha Kavach is an AI-powered smart surveillance system designed to protect agricultural fields from animal intrusion. The system detects the presence of animals using a camera and identifies them using a deep learning model.

When an animal is detected, the system alerts the farmer and activates a buzzer if necessary.
